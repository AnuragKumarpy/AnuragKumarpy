## 🚀 Flagship Engineering Projects

### 1. [RGCBot — Supergroup Ecosystem & Dynasty RPG Core](https://github.com/AnuragKumarpy/rgcbot)
- **High-Throughput Bot Architecture**: Built with Python 3.12, AsyncIO, PostgreSQL, Redis, Aiogram 3, and Telethon MTProto, deployed on AWS EC2.
- **Dynamic 1-5min TTL Engine**: Automated sweeper worker cleaning up command triggers and bot messages within 60s–300s to maintain pristine group aesthetics.
- **Anti-Userbot Math Verification**: Gated DM conversations behind cryptographic arithmetic challenges, defending backend Gemini LLM quotas from automated spam attacks.
- **Knowledge Base Search Engine**: Synchronized a 10,000+ word master manual to PostgreSQL with TSVECTOR GIN full-text indexing and in-memory BM25 fallback.

### 2. [EliteMusicAPI — Voice Chat Streaming Engine](https://github.com/AnuragKumarpy)
- **Lossless Voice Streaming**: Distributed WebRTC voice streaming engine delivering 320kbps 48kHz stereo audio into Telegram group calls.
- **Real-Time DSP Modifiers**: Dynamic server-side Bass Boost, 8D Spatial Audio, and speed pitch filters.
- **Multi-Assistant Hot Pool**: High-availability 7-assistant worker fleet pool for instant queue handoff and zero dead air.

### 3. [Copyright & Media Shield (@GCdenfenderRobot)](https://github.com/AnuragKumarpy/copyrightprotection)
- **Real-Time Media Defense**: Intercepts media leaks, deceptive edits, and unauthorized forward proliferation.
- **Granular Auto-Purge Windows**: Configurable auto-deletion from 0 seconds (instant burn) up to 48 hours across protected communities.

### 4. [DholRatri Tickets & University Event Platform](https://github.com/AnuragKumarpy/dholratri-tickets)
- **Campus Ticketing Web App**: Engineered for UPES university festival attendance with high-concurrency ticket purchasing.
- **Cryptographic QR Pass Scanner**: Integrated real-time gate validation scanner to eliminate counterfeit passes and duplicate entry.

### 5. [HiKUPES Student Utility Ecosystem](https://github.com/AnuragKumarpy/hikupes-user-app)
- **Campus Life Assistant**: Tailored for UPES students, featuring timetable schedules, academic notices, and campus services navigation.
